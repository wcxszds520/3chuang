## 包装与模型

建立 12 类可扩展包装目录：瓦楞纸箱、蜂窝板围箱、封闭木箱、框架木箱、金属运输箱、塑料周转箱、托盘化单元、袋装与压缩包、桶装、组合容器、卷盘、专用运输包装。纸箱另分常规、高身、扁平、长条结构。

“12 类”是本项目的工程分类，**不是行业规定的覆盖数量，也没有 95% 等覆盖率依据**。新增商品优先匹配包装结构与真实外尺寸；特殊开口、叉孔、支撑与重心条件仍需专用设定。当前界面能用已登记模板生成新规格；专用 GLB 上传与任意接触面登记尚未完成。

Blender MCP 构建并检查样板，CLI 验证新规格生成与可直接打开的 `.blend` 保存。Windows Computer Use 查看了 Blender 的八种样板结构；Chrome 查看了独立 Three.js 模型与生产页面。已生成 17 个真实规格资产，34 个完整/LOD GLB 均通过外包络检查。可编辑模型位于 `assets-src/blender/commerce-v4`。

完整模型三角面数：纸箱约 21,496，扁平箱 24,496，高身箱 25,840，长条箱 22,672，蜂窝围箱 18,200，木箱 52,044，整托 28,912，压缩包 132,368，新增周转箱 12,812。数字反映几何预算，不代表艺术质量已经通过。

## 算法与输入一致性

1. 组合搜索包含货墙、货块、货柱及真实余隙回填；候选仅从空间边界和允许方向生成，没有预设货位、隐藏货物、缩放包装或虚构填充物。
2. 同货主、同 SKU、同库存批号、同卸货组用于聚集；到仓批次另存。先卸组不能被后卸组堵住，也不能支撑后卸组。
3. 已规划货位可锁定；新增到仓货物不能移动锁定位。实际门洞、数量守恒、载重、方向、承托、顶载继续检查。
4. 演示订单补充 `SAME_SKU` 层数范围：同款层数与混堆总顶载分别验证。原始全包装层数输入保存在 `frozen-input.json`；差异见 `input-profile-diff.json`。物理尺寸、重量、数量、顶载数值及卸货顺序未改。港序统一为实际单目的港 1，三组交接保留为独立卸货顺序。
5. 来源明确的外部约束恢复自原始数据，不接受用包装设定修改来源尺寸、数量、重量或方向/层级规则。英文或空名称通过包装配置形成中文显示名，并保留原名和原始记录；这些名称不等于识别出了真实商品。

LIFO 几何通过不等于设备路径通过，也不等于可直接出运。当前货单尚无实际箱号、订舱截止时间和完整系固证据；未自行补造这些事实。

## 规则依据与适用边界

核对日期：2026-09-15。

- [IMO CTU Code](https://www.imo.org/en/ourwork/safety/pages/ctu-code.aspx)：2014 年非强制性全球装载与系固指导。不能把它说成某码头当天的统一入港截止规则。
- [IMO IMDG Code](https://www.imo.org/en/publications/pages/imdg%20code.aspx)：42-24 版自 2026-01-01 强制生效。当前实现不等于完整危险品隔离规则引擎。
- [SOLAS VGM](https://www.imo.org/en/ourwork/safety/pages/verification-of-the-gross-mass.aspx)、[ISPM15](https://www.ippc.int/en/archive-old-pages/phytosanitary-system/ispm-15-implementation/)：分别核对实际总重与木包装处理证据。
- [订舱截止时间](https://www.maersk.com/fr-fr/support/faqs/how-can-i-find-out-the-vessel-cut-off-time)随具体订舱/航次核对；[船公司箱型资料](https://www.hapag-lloyd.com/en/services-information/cargo-fleet/container/40-standard-high-cube.html)为参考，实际箱体规格可能不同。
