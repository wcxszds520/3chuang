# Yonggui Web Direction Selection

## 1. 项目目标

甬柜易算 Web 端不是答辩 PPT，也不是大屏驾驶舱。它应是一套真实用户能长期操作、评委能一眼理解、录屏时能证明真实能力的物流 AI 工作台。

目标用户：

- 中小卖家：需要低门槛录货和看懂风险。
- 货代配载员：需要柜型推荐、装柜依据、尾货处理建议。
- 仓库人员：需要 3D 作业步骤、路径、当前货物和目标位。
- 港前审核人员：需要合规矩阵、法规证据、人工复核和报告导出。

核心约束：

- 不使用红金、中国红、深色国赛风。
- 不使用深色大屏、赛博、蓝紫 AI 模板、营销官网。
- 不使用静态设计指标覆盖真实后端结果。
- 所有演示中的能力必须可真实点击、可失败、可复核。

## 2. 候选方向

### 方向 A：Enterprise Logistics Workspace

来源参考：Open Design `ant`、`enterprise`、`simple`。

特点：

- 浅色页面、白色卡片、港口蓝 CTA。
- 左侧模块导航 + 顶部订单状态 + 页面标题区。
- 数据摘要、表格、表单和审核矩阵统一。
- 状态标签清晰：PASS / WARNING / FAIL / DEGRADED。

适合点：

- 最适合真实物流 SaaS 和审核系统。
- 能承载真实接口失败、人工复核、导出物一致性。
- 低学习成本，适合现场演示和长时间操作。

不足：

- 如果只做默认后台，会显得普通。
- 需要通过 3D CAD 缩略、AI 解释面板和报告交付物增强产品记忆点。

评分：9.3 / 10

### 方向 B：Light AI Decision Desk

来源参考：Open Design `simple`、`shadcn`、`live-dashboard` 状态模式。

特点：

- 更强 AI 辅助区域，强调“建议、解释、证据”。
- 页面较轻，信息分区克制。
- 适合 VLM、DeepSeek、RAG 的状态展示。

适合点：

- 让 AI 能力显性但不过度装饰。
- 适合录屏讲解“AI 不替代规则，只做解释与辅助”。

不足：

- 容易变成普通蓝紫 AI SaaS 模板。
- 需要用物流数据、港口术语和真实失败态压住泛 AI 感。

评分：8.8 / 10

### 方向 C：Operations Control Table

来源参考：Open Design `dashboard` 的网格结构、`flowai-live-dashboard-template` 的表格/导出交互。

特点：

- 表格、矩阵和操作流最强。
- 信息密度高，页面更像配载/审核后台。
- 非核心装饰最少。

适合点：

- 很适合货物录入、合规矩阵、报告证据清单。
- 真实按钮和错误态容易落地。

不足：

- 工作台和 3D 页面主视觉会偏弱。
- 如果没有视觉重点，比赛演示记忆点不足。

评分：8.4 / 10

### 方向 D：Industrial CAD Twin

来源参考：Open Design `threejs` 技能思想、`craft/animation-discipline`、项目现有 Three.js。

特点：

- 浅色工业 CAD 画布。
- 当前货物、目标位、叉车路径、人工路径、风险描边、HUD。
- 强调“算法结果变成可执行作业流程”。

适合点：

- 最能体现项目差异化。
- 适合核心页 3D 作业孪生。

不足：

- 不适合作为全站视觉方向。
- 不能为了炫技破坏数据结构和性能。

评分：9.0 / 10，仅作为 3D 页专项方向。

## 3. 最终选择

最终方向：**Enterprise Logistics Workspace + Light AI Decision Desk + Industrial CAD Twin**

中文定位：**2026 现代浅色物流 AI 工作台 / 港前装柜智能决策系统 / 可复核的物流数字孪生 SaaS**

融合策略：

1. 全站壳层采用 Enterprise Logistics Workspace：清晰、可信、统一。
2. AI/VLM/RAG 区采用 Light AI Decision Desk：显示真实调用状态、建议、失败和证据。
3. 3D 页面采用 Industrial CAD Twin：浅色 CAD、真实装箱、作业流程。
4. 报告页采用 Operations Control Table 的交付结构：真实 HTML / CSV / JSON，避免假 PDF/ZIP。

## 4. 设计关键词

- 清爽：浅灰页面、白色卡片、低饱和背景。
- 专业：标题、数据、表格、证据链可复核。
- 可信：真实后端结果优先，失败态显式。
- 轻量：少阴影、少渐变、少装饰。
- 可执行：按钮对应真实动作或明确禁用。
- 可复核：每个风险项有依据、状态、人工复核入口。
- 低学习成本：中文主标题，操作路径短。
- 适合录屏：每页有一个明确讲解重点和可截图证据。

## 5. 不能采用的方向

- 红金国赛 PPT 风：适合答辩封面，不适合真实 Web 操作；会降低可信度和可读性。
- 深色大屏风：适合展示墙，不适合表格、表单、合规审查和仓库长时间使用。
- 蓝紫 AI 模板风：容易显得泛化，不能突出港前装柜业务。
- 营销官网风：用户进入系统是为了录货、推荐、复核、导出，不是阅读宣传页。
- 过度玻璃拟态：边界不清，表格和证据链可读性差。

## 6. 页面映射

| 页面 | 主方向 | 强化点 |
|---|---|---|
| 工作台首页 | Enterprise Logistics Workspace | 真实订单状态、主路径、最近任务、方案预览、报告入口。 |
| 货物录入 | Operations Control Table | 表单分组、SKU 表格、VLM 识别状态、AI 属性体检。 |
| 柜型推荐 | Light AI Decision Desk | 推荐主卡、柜型对比、真实后端结果、推荐解释。 |
| 3D 作业孪生 | Industrial CAD Twin | 真实 Three.js、HUD、路径、视角、算法依据。 |
| 合规预审 | Enterprise Review Desk | 合规矩阵、AI 审计状态、RAG 证据、人工复核。 |
| 报告导出 | Delivery Center | HTML/CSV/JSON 真实导出、操作留痕、数据一致性。 |
