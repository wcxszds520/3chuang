1. 打开 `http://127.0.0.1:4174/#dashboard`
2. 讲工作台：订单 NB2026-DEMO-01、221/221、84.51%、本地规则 WARNING / AI建议 PASS / 人工复核独立。

12. 下载全量 JSON，说明本轮不伪造 PDF/ZIP 接口。
