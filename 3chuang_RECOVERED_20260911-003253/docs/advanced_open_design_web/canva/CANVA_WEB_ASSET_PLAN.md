# Canva Web Asset Plan

本轮不生成 PPT，不修改任何 PPT 输出目录。Canva 仅作为后续制作 Web 演示素材和录屏封面时的规划参考。

## 1. 可制作素材

- Web 功能总览封面：使用 after contact sheet。
- 3D 作业孪生亮点图：使用 `3d-overview.png`、`3d-algorithm-reason.png`。
- 真实能力链路图：VLM → SKU → 柜型推荐 → 3D → 合规 → 报告。
- 录屏结尾页：展示 HTML / CSV / JSON 真实导出。

## 2. 禁止事项

- 不使用红金国赛 PPT 风替代 Web 截图。
- 不把 Web 页面做成大屏驾驶舱。
- 不把设计稿或截图当网页背景。
- 不在 Canva 中写真实 API Key。

## 3. 推荐尺寸

- 16:9 视频封面：1920x1080
- 文档插图：1600x900
- 评审材料图：1672x941 原截图比例

结论：Canva 可用于包装录屏材料，但不能替代真实 Web 运行证据。
