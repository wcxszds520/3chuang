# 07_PPT_STYLE_AND_DESIGN_REQUIREMENTS

本文用途：告诉 NotebookLM 生成 PPT 时应该采用什么视觉风格、信息密度和页面组织方式，避免廉价模板、卡片堆和文字爆炸。

## 总体风格

这套 PPT 应是正式国赛主稿，而不是普通课程汇报。建议整体方向是：

- 现代物流 SaaS
- 港口数字孪生
- 清晰、稳重、专业、有科技感
- 适合腾讯会议线上共享屏幕
- 每页一个核心观点
- 每页一个主视觉

可以使用浅色科技风、红金国赛风或港口工业风，但必须保证可读性。不要为了科技感牺牲文字清晰度。

## 页面信息原则

| 原则 | 要求 |
|---|---|
| 每页核心观点 | 一页只让评委记住一件事 |
| 主视觉 | 图片、截图或信息图必须解释内容，不是装饰 |
| 文字密度 | 普通页 60-150 中文字，技术页最多 220 中文字 |
| 数据使用 | 关键数字集中出现，不要每页重复 |
| 产品截图 | 大截图 + 局部放大 + 原生文字标注 |
| 真实边界 | 必须写清楚，不夸大 |

## 必须避免

- 廉价模板风。
- 每页几何卡片堆。
- 每页只有文字。
- 文字爆炸。
- 同一组数字反复出现。
- 截图被拉伸变形。
- 法规文档整屏贴图。
- 纯口号式价值页。
- 过度赛博大屏导致看不清。

## 截图处理要求

工作台截图要占页面 60%-70%，但不能糊成背景。关键区域需要局部放大镜：订单区、核心指标、下一步动作、报告入口。

合规页不要大面积贴法规文档。应该把法规证据裁成局部放大，旁边用原生文本标明“检查项 → 证据 → AI 解释 → 人工复核”。

3D 页必须是视觉高潮：真实 3D 小窗要清楚，但主画面要讲现场执行，不要只做小截图加文字。

## 内容边界

必须避免以下表述：

- 221/221 全部装入
- 84.51%
- 本地规则 WARNING / AI建议 PASS / 人工复核独立
- 实时联网国标检索
- 完全自动化
- 替代人工
- 全球首创
- 零风险
- 已商业化大规模落地
- 生产级全量系统

