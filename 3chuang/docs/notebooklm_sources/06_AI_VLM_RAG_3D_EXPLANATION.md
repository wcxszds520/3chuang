# 06_AI_VLM_RAG_3D_EXPLANATION

本文用途：把 VLM、RAG、DeepSeek、Three.js 四个答辩亮点讲清楚，尤其说明它们解决什么问题、输入输出是什么、真实状态和边界是什么。

## 1. VLM：拍照识别 + 人工确认

### 解决什么问题

港前装柜第一步是把货物变成可计算数据。中小卖家或现场人员不一定熟悉包装类型、木包装风险和字段填写。VLM 用图片识别辅助录入，降低现场数据采集门槛。

### 输入是什么

输入是货物图片，例如木托盘、纸箱、缠膜托盘、混合仓库货物等。前端会压缩图片并发送到 `/api/vlm/recognize-cargo`。

### 输出是什么

输出是结构化货物属性，包括货物描述、包装类型、是否木包装、风险标签、可信度等。前端把结果写入表单或待确认区域。

### 如何参与业务链路

VLM 位于“货物录入”阶段，帮助从现场图片到 SKU/包装风险字段的转换。它不是装箱决策者，而是让后续装箱和合规检查有更完整的数据输入。

### 真实状态

模型为 `Qwen/Qwen3-VL-32B-Instruct`。最新报告显示 5 张公开货物图片通过，前端上传 `pallet_wood.jpg` 通过。

### 当前边界

VLM 结果需要人工确认。识别失败时应回到手动录入，不展示假成功。不要写“所有图片都 100% 识别正确”。

### PPT 中应该怎么讲

建议讲：“VLM 把拍照变成待确认字段，帮助现场快速发现包装类型和木包装风险。”

### PPT 中不应该怎么讲

不要讲成“VLM 替代人工录入”“VLM 直接决定装箱方案”。

## 2. RAG：本地法规证据库 + AI 解释

### 解决什么问题

合规判断如果只给 PASS 或 FAIL，评委和用户都难以信任。RAG 的作用是让风险项能够回到法规证据，让结论可追溯、可复核。

### 输入是什么

输入是合规检查关键词或风险项，例如 VGM、LIFO、重心、IPPC、木包装、单证一致性、危险品。

### 输出是什么

输出是命中的法规文档、章节、分数和可解释依据。AI 可以基于这些证据生成更容易理解的说明。

### 如何参与业务链路

RAG 位于合规预审阶段。装箱结果出来后，系统把合规风险与法规证据关联，形成证据链。

### 真实状态

当前口径是“本地法规证据库 / RAG 检索 / AI 解释”。最新测试 9 个关键词全部命中。

### 当前边界

不要写“实时联网国标检索”。如果要讲联网参考，只能作为后续扩展或缓存参考，并需新的复测证据。

### PPT 中应该怎么讲

建议讲：“每条风险都能看到依据，不再是黑箱合规。”

### PPT 中不应该怎么讲

不要讲成“系统自动保证所有法规实时最新”。

## 3. DeepSeek：合规审计解释与报告建议

### 解决什么问题

确定性规则可以给出合规检查结果，但评委和用户需要知道为什么通过、哪里要复核、报告如何表达。DeepSeek 用来生成解释和建议。

### 输入是什么

输入是装箱方案摘要、柜型信息、重量、重心、装载结果、VGM、木包装、单证等合规上下文。

### 输出是什么

输出包括合规结论、评分、检查表、风险解释和整改建议。最新真实测试返回 本地规则 WARNING / AI建议 PASS / 人工复核独立。

### 如何参与业务链路

DeepSeek 位于合规预审和报告导出之间，帮助把算法与规则结果转成评委和用户能读懂的语言。

### 真实状态

模型为 `deepseek-v4-flash`，最新测试 `aiAdviceSource=ai`，合规结论为 本地规则 WARNING / AI建议 PASS / 人工复核独立。

### 当前边界

DeepSeek 不决定物理坐标，不覆盖确定性算法。外部服务失败时，前端应显示真实失败或降级，不伪装成功。

### PPT 中应该怎么讲

建议讲：“AI 负责解释和建议，硬规则由算法负责。”

### PPT 中不应该怎么讲

不要讲成“AI 自动判定所有物理装载结果”。

## 4. Three.js：3D 作业孪生

### 解决什么问题

装箱算法输出坐标后，如果现场工人看不懂，方案仍然无法落地。3D 作业孪生把坐标、顺序和目标位转成可执行画面。

### 输入是什么

输入是装箱引擎输出的 `loadedCargo`、`unloadedCargo`、`containerInfo`、`cog`、路径和作业步骤等数据。

### 输出是什么

输出是 Three.js 3D 画面，包括集装箱、货物块、视角切换、叉车路径、人工路径、目标位、算法依据弹窗等。

### 如何参与业务链路

它连接“算法结果”和“现场执行”。第 8 页应作为 PPT 技术高潮页，讲清楚从算法坐标到工人动作的转化。

### 真实状态

最新报告显示 3D 使用真实装箱结果渲染，canvas 非空白，多视角和按钮通过，保留真实数据结构。

### 当前边界

3D 是作业指导和孪生展示，不是自动驾驶叉车或无人仓系统。

### PPT 中应该怎么讲

建议讲：“算法算出坐标，3D 让现场知道怎么装。”

### PPT 中不应该怎么讲

不要讲成“系统已完全自动化控制现场作业”。
