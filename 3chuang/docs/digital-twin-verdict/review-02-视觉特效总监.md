## 1. 一句话诊断

**这个画面不是被引擎或参数"调坏了"，而是被"用室内影棚的光，去照一个户外港口的场景，还默认开着半透明线框箱壁"这件事从根上判了假**——环境贴图是 `RoomEnvironment`、半球光只有 0.32、环境强度只有 0.48、雾在 18 米就起，四件事叠加，让观众在第 1 秒就读出"灯箱里的 CAD 示意图"，而 GTAO、SMAA、pixelRatio 2 花掉的所有预算，都只是在给这张错误的图上抛光。

## 3. 光照重做方案

**结论：先不换 `RoomEnvironment`，但要把强度调对（0 成本、立刻见效），再换 2:1 阴天港口 HDRI（色温 6500–7000K）经 PMREM。** 室内棚四周都有亮面，所以金属在任何角度都有反射——这正是"棚拍感"的物理来源。港口 HDRI 的价值在于**天顶与地面的明确分离**。

| 光源 / 参数 | 现值 | 建议值 | 理由（ACES 前提下） |
|---|---|---|---|
| `environmentIntensity` | 0.48 | **1.0** | ACES 会压缩高光，env 翻倍后中间调整体上台，金属才有可读反射 |
| `HemisphereLight` | `('#eee9df','#252321', 0.32)` | **`('#e8e6de','#3d3a34', 1.15)`** | 地面色从近黑改成暖灰（户外地坪反弹不是黑的） |
| 主光 `key` | `('#fff1df', 3.2)` | 色与强度保留，位置 → `(-6,12,7)` | 3.2 在 ACES 下滚降到 ~0.85 是合理值；改位置为拿到 30–40° 侧面明暗分界 |
| 补光 `fill` | `('#d8e3ef', 0.7)` | **`('#cfe0ef', 1.0)`** | 天光反弹更冷、更强，托住暗面 |
| 轮廓光 `rim` | `('#f1f4ff', 2.1)` | **`('#f1f4ff', 1.4)`** | 2.1 会在箱体边缘烧出白描边，是"棚拍打边"的元凶 |
| 顶面光 `RectAreaLight` | 2.5 | **1.6** | 户外没有室内顶灯；2.5 会把顶面全提亮、吃掉阴影 |
| `toneMappingExposure` | 1.04 | **0.96** | env 翻倍 + hemi 翻 3.6 倍后必须收曝光 |
| `Fog` | `(18,48)` | **`(34,90)`** | 见上表 |

**光比建议：key : fill : rim ≈ 3.2 : 1.0 : 1.4**（主补比约 3:1，轮廓 ≤ 主光 45%）。户外阴天目标主补比 2.5–3.5:1，低于此会"平"，高于此会"硬棚"。
**配合原则**：`environmentIntensity`、`exposure`、`fog` 是一个三角——env 提了曝光必须降；雾色必须等于背景色，否则远景物体会比背景更白，立刻假。
**新增光源？不需要。** 想模拟天窗，提高 HemisphereLight 本身就是天光。

## 4. 材质与色彩空间审计

**做对的部分（不要动）**：`cargoPatternTexture` 走 `finishSharedTexture(..., {color:true})` → `colorSpace = SRGBColorSpace`（albedo 必须 sRGB ✅）；`cargoSurfaceTextures` 的 roughnessMap / bumpMap **没有**传 `color:true`，保持线性 ✅——这是最常见的着色错误来源，你避开了。

**必须改的：**
1. **`bumpScale = .001` 是死代码，不是"自我抵消"。** `:593` 这个值比可见阈值小两个数量级，肉眼完全不可见。想看到手感应给 **0.15–0.3**。`:597` 的 `normalScale 0.72` 本身合理，保留。
2. **放置件没有接到 bump/normal。** `createCargoObject`（`:966-977`）只设 `map`，`getMaterialProps()` 返回的 `bumpScale` 在这个路径里完全没被使用。接上即可，无需任何资产改动。
3. **贴图分辨率与过滤**：roughness/bump canvas 只有 128²，重复后高光下会出现 4px 块状。建议提到 **256²**，或显式设 `magFilter = LinearFilter`。
4. **anisotropy 不统一**：pattern 给了 8，容器贴花只给 4，坡道贴花 4。统一到 **8–16**。
5. **金属度归零**：`generic` 是 `roughness 0.85 / metalness 0.03`，纸箱不该有金属度，`metalness → 0`。

**"最少几张贴图能让纸箱可信"——3 张，100% 可程序化**：① baseColor（封箱带 + 标签，已有）；② roughness（0.82–0.90，带横向条带变化）；③ normal/bump（瓦楞方向）。**AO 不需要单独一张**，交给 GTAO 屏幕空间做。

**ACES 下材质区间**：集装箱哑光漆 `roughness 0.62→0.55 / metalness 0.30`；瓦楞纸箱 `0.85–0.92 / 0`；五金锁杆 `0.30–0.38 / 0.85–0.9`；塑料托盘 `0.38–0.50 / 0.02`；木托盘 `0.90`；缠绕膜 `0.22–0.32 / 0`；叉车漆 `0.55 / 0.30`。
⚠️ ACES 会压暗并轻微去饱和高光，**不要靠"把颜色调更艳"救叉车黄**，那会在高光处变成灰白。正确做法是提高 metalness 让它有反射。

## 6. 色彩与调色

- **主色调**：冷灰蓝工业底（`#9aa7ad`–`#c9d4d8`）+ 暖主体（纸箱 `#c9a06a`）。**当前最大色彩问题是变量太多**——暖木色、teal、蓝、红、橙多套分类色堆在一起像"彩虹积木"。建议**收敛到 2 个色系**（暖木 / 冷青），各自饱和度降 15%，点缀只留一个安全黄。
- **暗角：应该加，且要轻。** `PlanPreviewScene.jsx:154` 已有 `VignetteEffect({offset:0.3, darkness:0.36})`，TwinScene **完全没有**。建议 TwinScene 加 **`{offset: 0.35, darkness: 0.28}`**（比预览更弱，因为孪生要读数据，不能压暗边缘）。
- **白点与滚降**：env 提到 1.0 后建议 `exposure → 0.96`，主光色 `#fff1df` → `#fff6ea`（减黄）。**不要换掉 ACES。**

## 7. 档位策略裁决

**直接回答：GTAO 保留但必须降分辨率；SMAA 保留；`pixelRatio 2` 必须砍。**

理由：瓶颈在 CPU 提交 + 顶点，不在像素；但 `pixelRatio 2` 是**纯像素成本**，且会**同时放大 GTAO 与 SMAA 的每一个 pass**，是乘法关系。所以第一个砍的就是 pixelRatio，收益最大、损失最小。

- `pixelRatioFor`（`:804`）：high `min(dpr,2)→min(dpr,1.5)`；standard `min(dpr,1.5)→min(dpr,1.25)`。**省 30–44% 像素成本。**
- GTAO：high `resolutionScale 1→0.75`、samples `16→12`；standard `0.65→0.5`；`blendIntensity` standard `0.38→0.50`。
- SMAA：**一定要留**，极便宜且是唯一抗锯齿，边缘锯齿会被评委直接判"低质"。

**16ms 帧预算重分配（1080p@60）**：几何提交+阴影 ~7ms（靠实例化/合并降，不靠后处理）｜主渲染 ~4ms｜GTAO 3→1.5ms｜SMAA 1.2→0.8ms｜OutputPass ~1.0ms。
**一句话：真正吃预算的是 draw call，不是 pass。把 478 个可省 draw call 砍掉后，你可以把 pixelRatio 提回 1.75、GTAO 用全分辨率，画质反而更好。这是"先省后花"。**

**三档真正该差异化的地方**（不是简单开关后处理）：

| 维度 | 流畅 | 标准 | 极致 |
|---|---|---|---|
| pixelRatio | 1.0 | 1.25 | 1.5 |
| 阴影 | 1024² PCF | 2048² PCFSoft | 2048² PCFSoft |
| GTAO | **关** | 0.5 分辨率 × 8 | 0.75 分辨率 × 12 |
| SMAA | 开 | 开 | 开 |
| 环境反射 | **envMapIntensity 0** | 0.8 | 1.0 |
| 货物 LOD | 合并实例化、**无 edges** | 全量 + edges | 全量 + edges + 细节件 |
| 线框 / edges | 关 | 仅当前作业件 | 全开 |
| 骨骼动画 | 静态 | 动画 | 动画 |

⚠️ **当前三档的实际差异只有 pixelRatio + 阴影 + GTAO 开关，完全没有 LOD、没有环境反射分级、没有材质复杂度分级**——意味着"流畅档"仍要加载全量资产，**一个 draw call 都省不下来**。这是档位设计最大的漏洞。
