> 生成时间：2026-07-11
> 文件用途：描述甬柜易算在比赛提交时希望达到的最终系统形态，作为开发与验收基线。

## 一、目标态总体描述

甬柜易算在比赛提交时希望成为一套"港前装柜智能决策系统"，覆盖货物录入、SKU 管理、柜型选择、装箱算法、3D 装柜作业、合规预审、AI 解释、人工复核、报告导出完整主链路，并在演示数据集、算法利用率、3D 作业效率、法规联动、报告导出、联网检索、设计一致性七个维度达到目标态。

## 四、不在目标态范围内的事项

以下事项明确不在比赛提交目标态范围内，避免过度承诺：

- 生产级部署（域名/HTTPS/容器化/CDN）——当前为开发态部署。
- 多租户与权限分级——当前为单用户体系。
- 海关申报与物流追踪——非本系统主链路。
- 移动端原生 App——仅微信小程序。
- 实时多用户协作——当前为单用户流程。
- 算法在线学习/模型训练——当前为离线算法。
