# 02_PRESENTATION_STORYLINE

本文用途：为 NotebookLM 生成国赛/创赛 PPT 提供明确的 13 页叙事结构，避免生成空泛、重复数字或验收报告式幻灯片。

## 总体叙事

建议主线：**痛点人物 → 柜内风险 → 决策闭环 → 产品工作台 → VLM 录入 → 柜型边界 → 3D 作业高潮 → AI 边界 → 合规追溯 → 真实链路 → 应用价值 → 记忆收束**。

真实数据只在必要页面轻量出现，不要每页重复 NB2026-DEMO-01、40HQ、221/221、84.51%、本地规则 WARNING / AI建议 PASS / 人工复核独立。
