## 1. 需求梳理（把"乱"理清）

你的原始诉求拆解后是四层：

1. **目标层**：拿 CMIT 国赛一等奖（≤5% 概率的头部竞争，不是"完成度竞争"而是"记忆点竞争"）。
2. **赛道层**：先定赛道，再按赛道评分规则反推升级方向——这个顺序是对的，本方案照此执行。
3. **手段层**：视觉、交互、后端算法、立意、创意、主题**全部可以改**——即允许做伤筋动骨的重构，不允许的是推倒重来（6.3 万行代码、824 个测试、闭环已验证，这是资产不是包袱）。
4. **约束层**（你没说但客观存在）：
   - **时间**：按上届节奏（9/21 截止提交），距今约 5 周；校赛截止可能更早，**本周必须确认本校校赛时间**。
   - **规则红线**：已获其他赛事奖项的作品不得参赛；已商业发布的产品不得参赛（本项目未商业化，安全）。
   - **评审现实**：赛区是网评材料定生死，国赛是哈尔滨现场路演答辩——两套打法都要备。

## 3. 赛道论证

### 3.1 为什么是"自主命题 - 移动应用开发"

官方对该类别的定义（原文）："主要包括：Web 应用与开发、管理信息系统、移动应用开发（非游戏类）、**算法设计与应用**等类型……提供信息管理、信息服务、移动应用、算法设计等功能或服务。"

- 本项目 = Web 应用 + 算法设计与应用，**类别定义逐字命中**，不存在归类争议（作品说明 10 分中"作品分类正确"直接保住）。
- 竞争生态：该类别对手多为管理系统、小程序、校园应用——**3D 数字孪生 + 确定性装箱算法 + 多模态 AI 在此类别是降维差异化**；若去 VR 类反而要和 UE5 大作比沉浸感。

### 3.2 落选类别及原因

| 类别 | 落选原因 |
|---|---|
| 数据可视化 | 官方要求"基于真实、可靠的数据来源"，本项目数据为演示级，是可被评委质疑的硬伤；且项目本质是决策系统而非数据洞察 |
| 微信小程序应用设计 | 小程序是半成品（export 空壳、主色不统一），单独立不住；作为 Web 主系统的移动延伸才是加分项 |
| 虚拟现实VR与游戏 | 项目无 VR/AR/MR 交互形态，3D 可视化 ≠ VR，归类有争议风险 |
| 智能软硬件创意作品 | 无硬件实体 |
| 指定命题 7 个专项 | 元宇宙科幻/AIGC 创作/红色/乡村振兴/民族文化/中国故事/UE，与"港口装箱决策"内核不符，主题分必失 |

### 3.3 主题叙事（选题策划 20 分 + 国赛主题性）

- 官方主题"智能改变生活"落位：**改变的是 200 人以下中小外贸企业的日常**——慈溪小家电、宁波文具老板们"凭老师傅经验装柜"的现实。
- 宏观语境绑定（竞赛指南通篇关键词）：新质生产力、数字化赋能实体经济、外贸高质量发展、一带一路。
- 记忆点口号（沿用现有）："把每一个柜子装对、装稳、装合规"。
- **品牌统一（必须做）**：申报名"甬柜易算"与前端品牌"智港立方 PortCube"目前是分裂的。建议统一为 **智港立方 PortCube**（数字媒体竞赛气质更强，英文名利于国际化叙事），全端（Web/小程序/文档/PPT/视频）一次性统一，杜绝评委认知摩擦。

## 5. 升级方案（六大支柱）

### 支柱一：立意与市场性证据链（对应：选题 20 分 + 国赛市场性）

1. **真实用户调研**：问卷 + 深访 10~20 家宁波/慈溪中小外贸企业或货代（学校/家庭资源即可触达），产出《用户调研报告》：装柜现状、倒箱/退关经历、愿付意愿。**小规模真实数据 >> 任何编造的落地声明**，同时成为答辩最强素材。
2. **成本收益模型**：单柜节省测算（倒箱费 1500~3000 元/次 × 发生率 + 查验布控损失 + 人工配载工时），做成产品内"价值测算"小工具页（交互素材 + 市场性证据二合一）。
3. **行业数据引用**：引用公开行业报告（宁波港吞吐量、外贸企业数量、集装箱量）装点首页与文档，标注来源。
4. **品牌统一**：全端统一"智港立方 PortCube"，一个 logo、一套主色、一套文案语调。

### 支柱二：视觉系统重构（对应：视觉效果 30 分——最大单项）

原则：**不动 React 技术栈，做一次系统性视觉工程**，避免迁移风险。

1. **设计 token 化**：CSS variables 定义色板（1 主色 + 语义色 + 中性阶）、字号阶（配合中文字体规范：思源黑体/HarmonyOS Sans 或系统栈明确声明）、间距/圆角/阴影/动效曲线，全站组件统一消费。
2. **深浅双主题**：浅色为主（答辩投影仪友好），深色用于 3D 页；主色与 3D 场景色调（集装箱/货物/地面）统一调色。
3. **三大关键页面精修**（评委 90% 注意力所在）：
   - 首页：hero 视觉重做（3D 主视觉 + 数据背书带 + 一句话价值主张）；
   - 工作台：信息层级重排、卡片系统、状态色语义化；
   - 3D 孪生页：HUD 全面图标化+玻璃拟态或工业面板风格二选一，图表与 3D 视觉语言统一。
4. **3D 画面质感**：后处理链（已有 GTAO/SMAA）增加 Bloom 阈值调优 + 色调映射 + 体积雾/环境叙事（码头氛围：海面、龙门吊剪影、昼夜/黄昏光）；材质 PBR 参数统一（金属度/粗糙度规范表）；保证 1080p 投影下 60fps。
5. **文字规范清查**（评分表原文考"文字处理规范"）：全站中英文混排空格、标点、单位（mm/kg）、数字格式统一，出一份《UI 文案规范》。

### 支柱三：交互体验升级（对应：互动体验 30 分）

1. **新手引导**：首次进入 3 步 coach-mark 引导（录货 → 生成方案 → 看孪生复核），5 秒内让评委知道"这能干嘛、怎么玩"。
2. **一键演示模式（现场演示 10 分的保险丝）**：首页放"观看 5 分钟完整演示"入口——自动播放编排：真实订单导入 → 算法生成（进度可视化）→ 3D 作业孪生电影化运镜回放（配已有 TTS 讲解 + 字幕）→ 合规报告导出。评委零操作也能看到全闭环；现场断网/手抖时的一键兜底。
3. **3D 交互深化**：点击任意货物弹出档案卡（SKU/重量/目的港/LIFO 序号）；回放时间轴 scrubber + 倍速扩展至 16×（已有 backlog 项）；"装卸顺序"动态高亮（LIFO 逐件点亮）。
4. **算法可视化（本项目独有的互动创新点）**："算法竞技场"页——同一订单多引擎并排跑，实时显示各引擎利用率/重心/耗时，把 Orchestrator 的多策略择优从后端黑箱变成可玩的交互秀。这是"数据可视化"趣味与算法实力的结合，回答"你们的算法凭什么"。
5. **移动端闭环**：修复小程序 export 空壳、主色对齐 Web；答辩现场扫码进小程序体验"拍照识货"（VLM）形成多端互动记忆点。
6. **微交互补齐**：骨架屏、按钮态（hover/active/disabled）、操作 toast、数字滚动动画、页面转场。

### 支柱四：算法修硬伤与叙事化（对应：国赛技术性 + 素材新颖）

原则：**修硬伤 > 堆新算法**。824 个测试与确定性设计已是答辩武器，别推倒。

1. **慈溪场景利用率 39% → ≥70%**：Layered 引擎在该货型上失效。方案：将该类场景路由到 FastBlock/Realistic4D 并做参数调优；把"按货型自动择优引擎"本身做成卖点（与算法竞技场联动）。
2. **超时治理**：Realistic4D 1280 件超时 300s → 增加时间预算分支（超预算自动降级 fast-block 并告知），目标"任何输入 30s 内必有可用结果"。性能目标写实入文档：大规棋试单（如 1000 件）实测数据替代"400 件 <200ms"的旧口径。
3. **引擎瘦身**：清理 8 个历史引擎与未挂载路由（`routes\packing-v33.0-FINAL.js`），代码库整洁度本身就是完整性加分。
4. **算法故事线**：文档与视频中用"确定性优先、AI 克制"（引擎算物理/AI 判文案/人工终审三层）讲差异化——在 AIGC 泛滥的参赛作品里，"零幻觉合规架构"是清醒的反差记忆点。

### 支柱五：稳定性与现场演示保障（对应：现场演示 10 分）

1. **离线兜底演练**：DeepSeek/硅基流动/Tavily 全部走本地降级路径并实测（项目已有降级设计，缺的是演练与演示文案中的"优雅降级"展示）。
2. **Docker 化**：Dockerfile + docker-compose（MySQL + backend + web），一键拉起评审环境；补一条 GitHub Actions CI 跑后端测试（如有私有仓库顾虑则本地脚本即可）。
3. **演示预案文档**：5 分钟现场脚本（基于已有 08_SPEAKER_SCRIPT_5_MIN.md 改写）、设备/网络故障三级预案（本机兜底 → 录屏兜底 → 小程序兜底）。
4. **安全清理**：删除硬编码数据库密码脚本（`backend/scripts/migrate-add-fragile.js`）与 `.env` 入库风险——公开材料前必须清零。
5. **赛前冒烟**：Playwright 全量 E2E + API 27 项 + 手工走查清单，连跑 3 天无回归再冻结版本。

### 支柱六：参赛材料制作（对应：作品说明 10 分 + 赛区网评生命线）

赛区网评**只看材料**——材料就是产品的全部。已有 14 类文档是原料，需按竞赛格式重组为四件套：

1. **5 分钟演示视频（最高优先级）**：结构 = 30s 痛共鸣（真人/调研画面）→ 60s 方案总览 → 90s 核心技术（算法竞技场 + 确定性装箱）→ 90s 3D 孪生作业复核（运镜高光）→ 30s 合规溯源 + 多端 + 调研/价值数据收束。1080p/16:9/中文字幕/节奏卡点配乐。
2. **5~10 张图片**：首页、3D 孪生两张（不同视角）、算法竞技场、合规矩阵、小程序、架构图、调研照片，全部按统一视觉规范截取（3:2 或 16:9 裁切、统一标注字体）。
3. **作品介绍文档**：按官方要素（开发平台、主要软件、操作方法、亮点特色）重排现有 MASTER_FACTS，控制在评审 3 分钟可读完的密度。
4. **现场答辩 PPT**：沿用 16 页素材结构，视觉与全站新设计系统统一；备《评委问答手册》（已有 09_JUDGE_QA 基础，补：为什么不是 VR 类、数据来源、与商业软件差异、算法最优性边界）。
