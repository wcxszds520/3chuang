# Round 2 Visual Gap Report

## 1. 工作台首页

1. 当前实现评分：7.2 / 10
2. 与原设计稿差距：数据链路未统一，当前为 NB-CX-2026-0708 / 1148 件 / 62.4%；原稿为 NB2026-DEMO-01 / 221 件 / 84.51%。流程条为 5 步且偏扁，当前方案预览像条形图，不像 3D 集装箱缩略。
3. 页面主视觉是否明确：不够明确。原稿主视觉是“订单状态 + 流程 + 方案预览 + 风险摘要”，当前主视觉被普通指标卡和空白表格稀释。
4. 信息密度是否合适：偏散。下方三列比例和原稿不一致，风险摘要缺少强存在感。
5. 卡片、表格、按钮、状态标签是否统一：基础统一，但状态语义不统一，WARNING 风险链路不足。
6. 文案是否真实可信：偏通用，AI 建议和报告入口缺少真实港前审核语气。
7. 必须修复项：统一订单数据；改 4 步流程；指标采用 221/221、84.51%、本地规则 WARNING；方案预览改为多色货物块线框；补齐风险摘要和可交付入口。
8. 可选优化项：最近任务表加入进度条、操作列和风险状态。
9. 本页是否允许进入下一轮：不允许，需先修复到 >= 8.8。

6. 文案是否真实可信：需要换成 SKU-A01、SKU-C08 等可演示货物链路。
