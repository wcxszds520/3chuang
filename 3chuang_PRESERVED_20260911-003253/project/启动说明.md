# 🚀 甬柜易算 - 快速启动指南

## 一键启动（推荐）

### Windows 用户

```bash
# 双击运行
start-all.bat
```

### Mac/Linux 用户

```bash
chmod +x start-all.sh
./start-all.sh
```

## 手动启动

### 1. 启动后端服务器

```bash
cd backend
npm start
```

```

✅ 数据库连接成功
```

## 常见问题

### 端口被占用

**症状**: `Error: listen EADDRINUSE: address already in use :::3000`

**解决**:
```bash
# Windows
netstat -ano | findstr :3000
taskkill /F /PID <进程ID>

# Mac/Linux
lsof -i :3000
kill -9 <进程ID>
```

### 数据库连接失败

**症状**: `ER_ACCESS_DENIED_ERROR`

**解决**:
1. 检查 MySQL 是否运行
2. 验证 `backend/.env` 配置
3. 确认数据库已创建
